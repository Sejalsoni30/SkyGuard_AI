# SkyGuard AI

### Intelligent Multi-Cloud Storage Management Platform

SkyGuard AI is a full-stack multi-cloud storage management platform that provides a unified interface to connect, manage, monitor, and analyze files across multiple cloud storage providers.

It helps users manage their cloud accounts from a centralized dashboard, monitor storage usage, view and organize files, identify duplicate and unused data, generate storage analysis reports, and receive notifications.

## ✨ Features

- ☁️ Multi-cloud storage management
- 📊 Centralized storage dashboard
- 📁 Cloud file management
- 🔍 Duplicate & unused storage analysis
- 🔐 Secure authentication and OAuth integration
- ⚡ Background processing with Redis & BullMQ
- 🔔 Notifications and storage reports
- 🔗 Google Drive, Dropbox, OneDrive & GitHub integrations

## 🛠️ Tech Stack

**Frontend:** Next.js, React, TypeScript, Tailwind CSS, Zustand, React Query  
**Backend:** Node.js, Express.js, TypeScript, Prisma  
**Database:** PostgreSQL  
**Cloud & Services:** Google APIs, Google Drive, Dropbox, OneDrive, GitHub, Firebase  
**Infrastructure:** Redis, BullMQ, Docker & Docker Compose
